# Illustrated scene assets

Original flat storybook artwork generated for Soft Sky using the built-in image generation tool. All files are bundled locally; there are no external image services.

`scenes/`: four themes, each with day, sunset and night plates.
`layers/`: distant wisps and foreground cloud groups in three palettes, stars, sun with haze, a moon disk and separate moon haze.

The phase mask is calculated in ES5 and applied to the moon disk. Cloud groups and scenery are separate so color and motion can change without replacing forecast content. The images are decorative, not astronomical or geographic maps.
