Connection check

Having trouble finding a city or loading weather? Start here.

1. Check your connection

Run all seven tests. PASS means the request worked; FAIL means it needs attention.

2. If a test fails, open its link

Tap the matching link below—or try all four. Code-like text means the service opened. Use Safari’s Back button after each link to return here.

Older iPad? A certificate warning may appear.

Safari may say “Cannot verify server identity” for Open-Meteo. This is a security warning, not a permission the weather app needs. Check the iPad’s date and time, and review the certificate details. If Safari cannot verify the certificate, do not choose Accept or Continue just to make the tests pass. An expired or untrusted certificate needs to be resolved first; use a supported device if necessary.

3. Run the check again

After visiting the links, return here and run the tests again. Opening a service directly can help reveal the problem, but does not guarantee a fix.

If everything passes, go back to weather and try your city again. If a test still fails, include its name and error message when reporting the issue.
